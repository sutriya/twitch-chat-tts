# Озвучка чата Twitch

Читает чат канала Twitch и озвучивает сообщения в реальном времени бесплатным офлайн-синтезатором
[Silero](https://github.com/snakers4/silero-models) (нейросеть, работает на процессоре, без интернета).
Чат читается анонимно — токен и вход в аккаунт не нужны.

Основная модель `v5_6_ru` — 5 голосов с живой интонацией, лицензия CC BY-NC 4.0 (некоммерческая).
Можно поставить `model = "v5_cis_base_nostress"`: у неё 29 русских голосов (их говорят носители
языков СНГ, акцент возможен) и свободная лицензия MIT.

Silero понимает только кириллицу, поэтому перед озвучкой числа переводятся в слова
(«25» → «двадцать пять»), а латиница транслитерируется («sutriya» → «сутрия»).

## Установка

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

Модель (~150 МБ) скачается сама при первом запуске.

Активировать окружение (`.venv\Scripts\activate`) не нужно: команды выше вызывают Python из `.venv`
напрямую. В PowerShell активация часто падает с ошибкой «выполнение сценариев отключено в этой системе».

## Запуск

1. Впишите свой канал в `config.toml` → `[twitch] channel = "..."`.
2. Проверьте голос: `run.bat --say "Привет, чат!"`
3. Запустите двойным кликом по `run.bat` (или `run.bat --channel имя_канала` из консоли).

Вместо `run.bat` можно запускать напрямую: `.venv\Scripts\python main.py`.

Во время работы в консоли: `s` — пропустить, `c` — очистить очередь, `p` — пауза, `q` — выход (+ Enter).

Послушать все голоса по очереди: `run.bat --say "Привет, чат!" --voice all`

## Голос зрителя

Зритель сам выбирает себе голос командой в чате (выбор запоминается в `user_voices.json`):

| Команда | Что делает |
|---|---|
| `!голос 2` | второй голос из списка `speakers` в `config.toml` |
| `!голос baya`, `!голос бая` | голос по имени или русскому названию (`[voice_command.aliases]`) |
| `!голос сброс` | вернуть голос по умолчанию |

Бот читает чат анонимно и не может отвечать, поэтому после смены голоса он произносит
`confirm_text` новым голосом — зритель сразу слышит результат.

### Справка для зрителей

Готовый текст для панели под стримом (Twitch → «Изменить панели» → «Добавить текстовую панель»).
Номера соответствуют списку `speakers` по умолчанию — если поменяете список, поправьте и справку.

```markdown
**🔊 Озвучка чата**

Сообщения из чата читаются вслух. Выбери себе голос:

- **!голос 1** — Ксения
- **!голос 2** — Бая
- **!голос 3** — Ксюша
- **!голос 4** — Айдар
- **!голос 5** — Евгений
- **!голос сброс** — голос по умолчанию

Можно и по имени: **!голос айдар**. Голос запоминается, после смены бот скажет пару слов новым голосом.

Смайлы, ссылки и команды с «!» не озвучиваются.
```

## Звук в OBS

По умолчанию звук идёт в устройство Windows по умолчанию. Чтобы озвучка шла отдельной дорожкой,
поставьте [VB-Audio Virtual Cable](https://vb-audio.com/Cable/), посмотрите номер устройства через
`run.bat --list-devices` и укажите его в `[audio] output_device`. В OBS добавьте
«Захват входного аудиопотока» → `CABLE Output`.

## Настройки

Всё в `config.toml`: модель, голоса и скорость, свой голос для каждого зрителя, кого озвучивать
(все / сабы / VIP / модеры), режим «только по команде» (`only_with_prefix = "!tts"`),
игнор ботов, запрещённые слова, замены сокращений, длина сообщения и размер очереди.

## Файлы

- `main.py` — запуск, очередь озвучки, управление с консоли
- `twitch_chat.py` — анонимное подключение к IRC-чату Twitch
- `text_filter.py` — фильтры и чистка текста (смайлы, ссылки, «ааааа», замены)
- `text_normalize.py` — числа в слова и транслитерация латиницы
- `voices.py` — какой голос у какого зрителя, команда `!голос`
- `tts_engine.py` — синтез Silero и воспроизведение
